**Infor Birst — Practice Workspace**

Screenshots from hands-on practice with Infor Birst, covering the platform's three core areas: data modeling, interactive dashboards, and pixel-perfect (paginated) reporting. Built using Birst's sample data, not a real business dataset.

**What's included**
Data Modeling (Birst Modeler,Visualizer,Dashboard,Designer,Packages)
Star schema with fact tables (order details, orders, products) joined to customer, employee, product, shipper, and supplier dimensions

**Interactive Dashboards (Birst Visualizer & Dashboard)**
Sales Overview and Product performance pages with KPI cards, CY vs LY combo charts, Group Filter , cross-drill navigation buttons, and a geographic map visual

**Pixel-Perfect Reports (Birst Designer)**
Customer, Sales CY/LY, and Procurement reports — paginated, print-ready output, a distinct skillset from interactive dashboard design

**Why this is here**

I've spent significant hands-on time in Birst, so this repo is meant to show that comfort with the tool — modeling, dashboarding, and paginated reporting — rather than stand as an analysis project like my other repos.

**Tools**
Infor Birst (Modeler · Visualizer ·Dashboard. Designer)
